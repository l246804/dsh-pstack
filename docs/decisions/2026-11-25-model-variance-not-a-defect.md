# 决策：模型偶发行为只降低概率，不做运行时兜底

## 背景

随包技能和文档用相对路径互相引用，模型读取时偶发解析到错误目录，第一次失败、重试恢复。Issue #36 记录了四类错误路径，PR #50 为此增加运行时路径索引：启动时扫描技能目录，把绝对路径写进 `$DSH_HOME/pstack/paths.json`。实现后在真实会话里复测，失败仍是低频偶发，重试即恢复，索引没有把失败率降到可察觉的程度，Issue #36 和 PR #50 均已关闭。

同类现象还有长上下文后期的指令遵循漂移（Issue #47）。这些问题的共同点是同一提示、同一环境下结果不稳定，重试可能恢复，改文档措辞或工具边界只能改变概率。

## 决策

模型偶发行为按概率降低处理，不按缺陷修复。

- 改动只落在能稳定影响模型选择的地方：适配文档的措辞、工具描述的边界、Agent preset 的可用工具，以及场景复跑时的命中率。
- 不引入运行时兜底索引，不为偶发行为增加新的全局状态。
- 验收看同一提示重复运行的命中率，例如 5 次里失败几次，不看单次通过或单次失败。
- 报告这类问题使用模型行为模板，附重试结果和出现频率；没有可测频率之前不进入修复流程。

## 替代方案

**运行时路径索引（PR #50）。** 启动时扫描技能目录，把绝对路径写进 `$DSH_HOME/pstack/paths.json`，让模型不再推算相对路径。它能消除推算这一步，但增加启动期扫描、额外文件读取和缓存失效的成本，而实测中失败仍是低频偶发、重试可恢复。收益不足以抵消新增的状态，已关闭。

**给工具或路径改名。** 让相似的名字不再相似，可能降低误选。属于破坏性 API 变更，且没有证据表明名字是主因，未采用。

## 后果

- 偶发失败仍会发生，用户按重试处理。
- 文档和工具措辞的改动按命中率评估，不承诺零失败。
