# 决定：插件配置页默认提供中英双语

Status: proposed
Date: 2026-10-30
Scope: src/client/**, tests/**, locale/**
Implemented-by: -
Review: 2027-04-30

## 背景

插件配置页面向 DSH 的中英文用户。新增角色模型配置页时，中文文案曾存在英文残留；配置页属于产品界面，不能依赖用户自行翻译或浏览器翻译。后续在配置页增加功能时，如果只补英文，会再次产生同样的双语缺口。

## 决定

所有插件配置页的可见文案必须通过 `src/client/locales.ts` 的本地化字典提供，并同时维护完整的 `en` 与 `zh` 词典；新增配置页功能时必须在同一个改动中补齐两种语言。`tests/role-page.test.tsx` 校验 `en` / `zh` 键集合一致并至少渲染一次中文页面；`locale/en.json` 与 `locale/zh.json` 的插件元数据保持对应语言。

## 备选方案

- 只提供英文文案。不选：中文用户无法在配置页完成操作，违背产品双语目标。
- 依赖浏览器自动翻译。不选：无法保证术语一致，翻译质量和不支持翻译的 Electron/WebView 环境不可控。
- 一次性补齐 DSH 支持的八种语言。不选：当前项目只承诺中英双语，扩到八种会显著增加翻译维护成本；以后需要时再扩展。

## 后果

配置页保持中英双语一致，新增功能的改动范围包含两种词典与对应测试。代价是每个配置页功能都要同时维护两份文案；若将来增加第三语言，需要扩展字典与测试。
