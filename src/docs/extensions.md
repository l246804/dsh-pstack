# port 本地扩展

本文件记录非 gap 移植、由本插件主动提供的扩展功能。普通适配和 bug 修复不在这里重复。

## 记录规则

- 只记录会改变用户可见功能、命令、配置或 UI 的扩展。
- 每条记录用户目标、边界和对应测试或实现文件。
- 不复制代码、schema、参数表或完整 UI 文案；这些以源码和测试为准。
- 普通缺陷、回归和移植坑放到 [regressions.md](./regressions.md)。
- 由 playground 缺口分析产生的适配功能，来源留在 playground 分析/快照，不在这里重写。

## 当前扩展

| 能力类别 | 用户目标 | 状态 |
| --- | --- | --- |
| 插件配置入口 | 用户可在插件详情页集中进入下述配置能力。 | 已实现 |
| 推荐插件管理 | 用户可查看推荐插件及状态，并管理与本插件配合的官方插件。 | 已实现 |
| 角色模型配置 | 用户可在插件界面查看和编辑角色路由，无需手动改写配置文件。 | 已实现 |
| 工作流开关 | 用户可在会话输入区开关 Poteto 工作流，并在配置弹窗设置新会话默认值。 | 已实现 |

## 验证

- 对应实现和测试位于 `src/`、`tests/` 和 `playground/`；具体模块边界见 [../../src/AGENTS.md](../../src/AGENTS.md)。
- 新增扩展前先确认它不能由 playground 缺口移植直接满足。
- 扩展改变发布兼容性时，按 [../../docs/release.md](../../docs/release.md) 更新兼容表分组和 README。
