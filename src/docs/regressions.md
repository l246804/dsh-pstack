# 移植回归检查

本文件登记重复移植问题对应的当前约束和验证入口。普通缺陷由修复提交和测试留存。

## 记录规则

- 只登记有复现证据的重复移植问题，每条给出触发条件、当前约束和可重跑的行为检查。
- 实现变化时更新对应检查；失效项删除。

## 新增流程

1. 用复现证据确认重复移植问题，并补齐对应的行为检查。
2. 登记触发条件、当前约束与验证入口；修复细节留在提交和代码中。
